# Changelog

## 0.3.0 (2026-10-24)

Needs orgwarrior 0.4.0 and orgwarrior-web 0.4.0.

- **`orgwarrior-mcp service`** prints a systemd unit, or a launch agent on
  a Mac, that keeps the server running, with the full paths filled in.
- Plainer error messages, for Claude and for you.
- The README is rewritten to be shorter and clearer, and points to
  `orgwarrior --check` for checking your setup.

## 0.2.1 (2026-10-23)

Needs orgwarrior 0.3.0.

- **Read-only files**: Claude is told what a task marked "read only" is (a
  task in a file that isn't writable, usually a copy of another calendar)
  and that changes to it are refused, so it tells you instead of trying
  again.

## 0.2.0 (2026-10-22)

Needs orgwarrior 0.2.0.

- `set_when`: change or remove an event's date.

## 0.1.0 (2026-10-22)

- First public release.
